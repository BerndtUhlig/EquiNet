### README 

This test case requires the ShapeNetPart Dataset which can be found here:

https://www.kaggle.com/datasets/majdouline20/shapenetpart-dataset


Once downloaded, place one of the folders denoting an object type (e.g. 02691156) into the ShapeNetPart folder 
and set the number as a string variable into the respective datasets in `run_ShapeNet.py` (default is 02691156). 

Then simply run  `run_ShapeNet.py`.
Be sure to install all requirements in the respective files.
